Accelerated by y-cruncher by Alexander J. Yee. Inspired by Nateate’s Pi Explorer video ↗. Compute real decimal places, then reinterpret the same digits as text, color, or pixels.

01 / GENERATE

Automatic measures free RAM before a run. Calculations that fit use RAM; larger ones process bounded arithmetic blocks through temporary disk files. Windows asks to approve only the calculator worker for disk mode. Scratch files are cleared after use, and the new dataset appears after the complete output is verified. Newly generated caches share a 2 GiB budget; imported files and the active dataset are protected.

02 / REINTERPRET

Letters: pair digits, take modulo 26, map 0–25 to A–Z. Zoom blends full glyphs, fine glyphs, microglyphs, then row coverage; these levels use the actual font shapes. Color: one digit, one color. Pixels: 0–4 black, 5–9 white; or select odd/even below.

03 / FIND A SHAPE

Click or drag in the pixel editor. All black and white cells inside the cropped bounds must match. Width sweep rearranges the same stream at every selected width. Native bitset intersections search millions of candidate starts at once.

04 / STAY CURIOUS

π is infinite and nonperiodic. Whether it is normal—and contains every finite digit sequence—is unproved. Estimated odds assume independent uniform digits; a finite search cannot prove or disprove that conjecture.
